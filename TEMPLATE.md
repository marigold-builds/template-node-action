# Using this template

A checklist for the first fifteen minutes. Delete this file when you're done.

1. `action.yml:1` — `name`.
2. `action.yml:2` — `description`.
3. `action.yml:3` — `author`, if it's not staying "Marigold Builds".
4. `README.md` — fill in every `<placeholder>`, including the `uses: marigold-builds/<name>@v0.1.0` example.
5. Delete `TEMPLATE.md`.
